VoiceAgents operates a comprehensive directory and comparison platform for AI voice agents and AI receptionists. The site lists 198 voice AI vendors, offering detailed information on pricing models, language support, telephony integration, compliance, and direct links to each vendor’s source. Users can explore products, read guides, and request tailored recommendations through an interactive questionnaire, helping businesses select the right voice AI solution for their needs.

**Areas:** Contact-centre voice AI · AI receptionists · Voice agent platforms · Voice AI APIs · Outbound and sales calling · Healthcare voice AI · Hospitality voice AI · Open-source voice frameworks

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for VoiceAgents: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
